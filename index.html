How I work

From raw file to a decision someone can make

The same four steps run through each project below, regardless of the dataset.

01

Extract & clean

Pull raw CSVs or tables, fix inconsistent formats, remove duplicates and validate against source counts.

02

Model & query

Structure relationships in Power Query or SQL, then write joins and aggregations against the real question being asked.

03

Visualize

Build dashboards in Power BI or Excel with the metrics that matter surfaced first, not buried in a table.

04

Communicate

Summarize what changed, why it matters and what it suggests doing next — in plain business language.
